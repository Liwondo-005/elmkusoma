# School Images Download Guide

## How to Download (Free, No Copyright Issues)

Go to https://unsplash.com/s/photos and search for each term below.
Click the image → Click "Download" → Save with the exact filename listed.

### Tips
- Search the term in quotes for best results
- Any image from Unsplash is free to use
- Download the "Small" size (it's sufficient for web cards)
- Save to the folder listed under "Save To"
